# How to communicate

When explaining code or answering questions in chat, write plain, simplified technical English
(in the spirit of ASD-STE100, not its strict dictionary):

- Prefer short sentences with one main idea each. Split a sentence when it carries several ideas.
- Prefer the active voice and the present tense. Use past or future tense when the facts need it.
- Use the same term for the same concept throughout an answer. Do not vary words for style.
- Keep technical names, file names, and code tokens exactly as written.
- Lead with the action or the outcome. Skip filler preamble.
- Clarity wins over these guidelines. Keep a longer sentence when splitting it would lose meaning.
